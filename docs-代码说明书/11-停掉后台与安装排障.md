# 11 · 怎么停掉后台、以及装不上怎么办

> 场景：要安装新版本 / 要重新打包，系统提示"文件正在使用""无法覆盖"或者"端口被占用"。
> 根因几乎总是同一个：**旧程序还在后台跑着，它占着自己那几个文件。**

---

## 一、先判断：到底有没有在跑

不要凭感觉。打开 **PowerShell**（开始菜单搜 `PowerShell`），粘这行：

```powershell
Get-Process 账管卫士 -ErrorAction SilentlyContinue |
  Select-Object Id, ProcessName, StartTime, Path
```

**有输出** = 还在跑（会列出进程号 PID 和程序路径）。
**没输出** = 确实没在跑，那装不上是别的原因（看第四节）。

顺便看端口（本程序用 8080）：

```powershell
Get-NetTCPConnection -LocalPort 8080 -State Listen -ErrorAction SilentlyContinue |
  Select-Object LocalPort, OwningProcess
```

---

## 二、方法一：任务管理器（不用敲命令，给非技术人员用）

1. `Ctrl + Shift + Esc` 打开**任务管理器**
2. 若只看到"简略信息"，点左下角 **详细信息**
3. 切到 **详细信息** 页签，找到 **账管卫士**
   （通常有**两个**，都要结束 —— 一个是启动器，一个是真正的 java 程序）
4. 右键 → **结束任务**
5. 确认列表里再也找不到"账管卫士"

> ⚠️ 注意别结束错：列表里的 `java.exe` / `javaw.exe` 也是它，一并结束；
> 但不认识的其他进程不要动。

---

## 三、方法二：PowerShell 一条命令（快，推荐自己用）

```powershell
Get-Process 账管卫士 -ErrorAction SilentlyContinue | Stop-Process -Force
```

`-Force` = 强制结束。这一行会把**所有**同名进程一起干掉，不用一个个找 PID。

**想看清楚再动手**，分两步：

```powershell
# 第 1 步：先看看是谁
Get-Process 账管卫士 | Select-Object Id, StartTime

# 第 2 步：按进程号精确结束（18756 换成你看到的数字）
Stop-Process -Id 18756 -Force
```

**验证是否真停了**（两条都应无输出）：

```powershell
Get-Process 账管卫士 -ErrorAction SilentlyContinue
Get-NetTCPConnection -LocalPort 8080 -State Listen -ErrorAction SilentlyContinue
```

### 懒人版：存成 bat，以后双击就停

```bat
@echo off
chcp 65001 >nul
echo 正在停止账管卫士...
powershell -NoProfile -Command "Get-Process 账管卫士 -ErrorAction SilentlyContinue | Stop-Process -Force"
powershell -NoProfile -Command "Get-Process java,javaw -ErrorAction SilentlyContinue | Stop-Process -Force"
timeout /t 2 /nobreak >nul
echo.
echo 已停止。现在可以安装新版本了。
pause
```

## 四、停了还是装不上：四种常见情况

### 1）旧版本装过，卸载程序还在占文件

Inno Setup 装的版本在：

```
C:\Users\<用户名>\AppData\Local\Programs\账管卫士\
```

报"无法写入"就走正规卸载：**Windows 设置 → 应用 → 搜"账管卫士" → 卸载**，再装新的。
⚠️ 卸载会连数据目录一起删（`.iss` 里的 `UninstallDelete`），
**卸载前若还要数据，先把装目录下的 `data` 文件夹复制出来。**

### 2）杀毒软件锁了文件

360 / 火绒 / Defender 有时会锁住刚下载的 exe。把 `out` 加白名单，或复制到别的目录再试。

### 3）解压不完整（绿色版特有）

双击 exe 报 **Failed to launch JVM**，90% 是这个：

> 在压缩包窗口里直接双击了 exe。Windows 只把 exe 单独解到临时目录，
> 它旁边没有 `runtime\`，找不到自带 Java 运行时。

**正确做法：先整个文件夹解压出来，再进文件夹双击。**
判断标准：**exe 旁边必须同时看得到 `app\` 和 `runtime\` 两个文件夹。**

### 4）8080 被别的软件占了

程序有自动让位机制（依次试 8081 / 8082 / 18080）。想固定端口：

```bat
账管卫士.exe --server.port=18080
```

## 五、停之前要不要担心数据？

**不用担心。** 两点：

1. 数据在 `data\erp.db`，SQLite 是**崩溃安全**的：写入要么全做要么全不做，
   强杀进程不会把库写坏（最坏是丢掉最后那个未提交的操作）。
2. 程序每次**启动**自动备份一次到 `backup\`，每晚 23 点再备一次，保留 30 份。

**但如果正在过账大额单据，还是先让它做完。** 想保险就先复制一份 `data` 文件夹。

## 六、完整流程（建议照这个顺序）

```
① 备份 data 文件夹（可选但推荐）
        ↓
② 停进程：任务管理器结束"账管卫士"，或 PowerShell 一行命令
        ↓
③ 验证：Get-Process 查不到、8080 已释放
        ↓
④ 卸载旧版（若装过）
        ↓
⑤ 安装新版：双击 账管卫士-Setup-0.6.0.exe
      （绿色版：整个解压 → 双击 exe）
        ↓
⑥ 验证：浏览器自动打开 http://localhost:8080，能登录 admin / admin123
```
